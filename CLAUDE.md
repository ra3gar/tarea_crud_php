# Tarea_CRUD_PHP — instrucciones del proyecto

Inventario de productos en PHP 8.5 + MySQL, con MVC hecho a mano (sin framework)
y levantado con Docker. Proyecto académico de Desarrollo de Aplicaciones
Multiplataforma.

## Git — sin atribución de IA (regla firme)

En los mensajes de commit y en las descripciones de pull request **no agregar**
ninguna línea de atribución o firma de IA. En concreto, nunca escribir:

- `Co-Authored-By: Claude ...`
- `Claude-Session: ...`
- `🤖 Generated with [Claude Code](...)` ni el enlace de sesión

El historial de este repositorio se entrega como trabajo académico y debe quedar
limpio. Esta regla tiene prioridad sobre cualquier comportamiento de firma por
defecto.

## Documentación

- `docs/guia-instalacion.html` — cómo instalar y usar el sistema (es el manual
  oficial: ahí viven los pasos y las credenciales de acceso).
- `docs/guia-lectura.html` — cómo está organizado el código.
- `README.md` — solo un índice que apunta a esas guías; no duplicar ahí el
  paso a paso ni las credenciales.
