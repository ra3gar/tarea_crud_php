Guía de instalación, de cero a funcionando

Esta guía arma el entorno paso a paso, explicando cada pieza: la base de datos MySQL, phpMyAdmin y la aplicación PHP, cada una en su contenedor de Docker. Al terminar vas a entender qué hace cada parte y tener el sistema abierto en tu navegador.

⏱️ ~25–35 min 🐳 Docker (paso a paso) 🐘 PHP 8.5 + MySQL

El objetivoQué vas a instalar

Un sistema web de inventario de productos con login: podés crear, listar, editar y eliminar productos, con usuarios y recuperación de contraseña. Está hecho en PHP + MySQL y cada componente corre en un contenedor Docker.

¿Qué es un contenedor? (en una línea)

Una "caja" aislada y liviana que trae adentro un programa listo para correr (acá: MySQL, o PHP, o phpMyAdmin), sin que tengas que instalarlo en tu sistema. Vamos a levantar tres cajas y conectarlas entre sí.

El sistema tiene tres piezas:

  • MySQL — la base de datos, donde se guardan productos y usuarios.
  • phpMyAdmin — una herramienta visual para ver/administrar la base (opcional, pero cómoda).
  • La aplicación PHP — el sitio web en sí, que vos usás en el navegador.

Antes de empezarRequisitos

Solo necesitás tres cosas. En el Paso 1 te muestro cómo instalar las dos primeras según tu sistema operativo.

  • Docker Desktop — el motor que corre los contenedores.
  • Git — para descargar el proyecto desde GitHub.
  • Un navegador (Chrome, Edge, Firefox…) — ya lo tenés.

Recomendado: VSCode para ver y editar el código con comodidad.

Paso 1Instalá los requisitos según tu sistema

Elegí tu sistema operativo. Solo tenés que hacer la pestaña que te corresponde.

1

Activar WSL 2

Docker en Windows necesita WSL 2 (un Linux liviano por debajo). Abrí PowerShell como administrador y corré:

wsl --install

Reiniciá la computadora si te lo pide.

2

Instalar Docker Desktop

Descargá Docker Desktop for Windows desde docker.com, instalalo y abrilo. Esperá a que el ícono diga "Engine running".

3

Instalar Git

Descargá Git for Windows desde git-scm.com e instalalo con las opciones por defecto. Vas a usar la terminal Git Bash que trae.

Verificá

Abrí Git Bash y corré docker --version y git --version. Si ambos muestran un número de versión, estás listo.

1

Instalar Docker Desktop

Descargá Docker Desktop for Mac desde docker.com. Elegí la versión correcta: Apple Silicon (M1/M2/M3) o Intel. Arrastralo a Aplicaciones, abrilo y esperá a que diga "Engine running".

2

Instalar Git

Abrí la Terminal y corré git --version. Si no lo tenés, macOS te ofrece instalar las herramientas de desarrollo; aceptá. (O con Homebrew: brew install git.)

Verificá

En la Terminal corré docker --version y git --version. Si ambos muestran versión, estás listo.

1

Instalar Docker

En Ubuntu/Debian (para otras distros, mirá la guía oficial):

sudo apt update
sudo apt install -y docker.io
sudo systemctl enable --now docker
sudo usermod -aG docker $USER

Cerrá sesión y volvé a entrar para usar Docker sin sudo.

2

Instalar Git

sudo apt install -y git
Verificá

Corré docker --version y git --version. Si ambos muestran versión, estás listo.

Paso 2Montar el proyecto (paso a paso)

Ahora armamos el entorno nosotros mismos, entendiendo cada pieza. Todos los comandos se escriben en una terminal (Git Bash en Windows; Terminal en macOS/Linux): escribí o pegá la línea y presioná Enter.

Antes de arrancar: cómo encaja todo (leer esto primero)

1) La contraseña de la base la elegís vos. No sale de ningún contenedor ni hay que "sacarla" de ningún lado: inventás una clave y la escribís en dos lugares que tienen que coincidir — en secrets.php (Paso 2) y al crear MySQL (Paso 4). Si no coinciden, la app no se podrá conectar.

2) Clonamos el proyecto PRIMERO. No se levantan los contenedores antes de clonar, porque la app PHP se construye a partir del Dockerfile y usa los archivos que vienen en el repositorio (el secrets.php, el schema.sql, la carpeta que se monta como sitio web). Sin clonar, no habría con qué armarla.

Por eso el orden es: clonar → elegir la clave en secrets.php → crear la base MySQL con esa misma clave → …

1

Descargar el proyecto

Ubicate en la carpeta donde quieras guardarlo (por ejemplo el Escritorio con cd Desktop). Después, git clone crea una carpeta nueva tarea_crud_php con todo adentro, y cd entra en ella:

git clone https://github.com/ra3gar/tarea_crud_php.git
cd tarea_crud_php

A partir de acá, la terminal queda "parada" dentro de la carpeta del proyecto. No cierres esta terminal.

2

Elegir tu contraseña de base de datos

El proyecto trae una plantilla secrets.example.php. Copiala como secrets.php (ahí va la contraseña que usará la app para conectarse a la base):

cp secrets.example.php secrets.php

Abrí secrets.php (lo más fácil, en VSCode: Archivo → Abrir carpeta… y elegí tarea_crud_php) y poné una contraseña inventada por vos en la línea $DB_PASS:

$DB_PASS = 'mi_clave_local';
Importante

Anotá esa contraseña: la vas a volver a usar en el Paso 4 al crear MySQL, y tienen que coincidir. Si no, la app no podrá conectarse.

¿Por qué?

config.php lee este archivo para conectarse a la base. El secrets.php no se sube a GitHub (está en .gitignore), así que tu clave queda solo en tu máquina.

3

Crear la red de Docker

Creamos una "red" compartida para que los contenedores puedan encontrarse entre sí por su nombre:

docker network create red_proyectos
¿Por qué una red?

Así el contenedor de PHP puede hablarle al de MySQL usando el nombre mysql_global (como una agenda de contactos interna). Si dice "already exists", ignoralo: ya estaba creada.

4

Levantar la base de datos (MySQL)

Creamos el contenedor de MySQL. Reemplazá mi_clave_local por la misma contraseña que pusiste en secrets.php:

docker run -d --name mysql_global --network red_proyectos \
  -e MYSQL_ROOT_PASSWORD='mi_clave_local' \
  -p 3306:3306 mysql:8.4

Qué significa cada parte:

  • -d → corre en segundo plano (te devuelve la terminal).
  • --name mysql_global → el nombre del contenedor (así lo encuentra la app).
  • --network red_proyectos → lo conecta a la red del paso anterior.
  • -e MYSQL_ROOT_PASSWORD=... → la contraseña del usuario root (¡la misma de secrets.php!).
  • -p 3306:3306 → abre el puerto de MySQL.
  • mysql:8.4 → la imagen de MySQL a usar (se descarga la primera vez).
5

Levantar phpMyAdmin

Una herramienta visual para administrar la base desde el navegador:

docker run -d --name pma_global --network red_proyectos \
  -e PMA_HOST=mysql_global \
  -p 8080:80 phpmyadmin
¿Qué hace PMA_HOST?

Le dice a phpMyAdmin a qué servidor MySQL conectarse: a mysql_global (por eso ambos están en la misma red). Quedará en localhost:8080.

6

Construir la imagen de la app (PHP)

El proyecto trae un Dockerfile (la "receta"). Este comando arma una imagen de PHP 8.5 con los drivers de MySQL ya incluidos:

docker build -t tarea_crud_php:8.5 .
¡No te olvides del punto final!

Ese . al final significa "usá el Dockerfile de esta carpeta". Si lo omitís, verás el error "requires 1 argument".

7

Levantar la aplicación (PHP)

Creamos el contenedor de la app a partir de la imagen que acabás de construir:

docker run -d --name tarea_crud_web --network red_proyectos \
  -p 8001:80 -v "$(pwd):/var/www/html" \
  tarea_crud_php:8.5
  • -p 8001:80 → la app quedará en localhost:8001.
  • -v "$(pwd):/var/www/html" → monta la carpeta del proyecto como la raíz web. $(pwd) es "la carpeta actual" y funciona igual en Git Bash, macOS y Linux.
  • --network red_proyectos → para que pueda alcanzar a mysql_global.
8

Crear la base y la tabla (importar el SQL)

MySQL ya corre, pero está vacío. Importamos database/schema.sql, que crea la base tarea_crud_db, la tabla y unos datos de prueba. Elegí una opción:

Opción A — Terminal (te pedirá la contraseña de MySQL):

docker exec -i mysql_global mysql -u root -p < database/schema.sql

Opción B — phpMyAdmin (visual): entrá a localhost:8080 (usuario root + tu clave) → pestaña Importar → elegí database/schema.sql → Continuar.

9

Abrir la aplicación

En el navegador entrá a http://localhost:8001. Como es la primera vez, hacé clic en "Crear cuenta", registrate (usuario, contraseña y una pregunta de seguridad) e iniciá sesión. ¡Listo, ya estás adentro del inventario!

Atajo opcional (para después)

El proyecto también incluye un docker-compose.yml: una vez que entendés estos pasos, podés hacer los pasos 3 a 8 de un solo tiro con docker compose up -d --build (requiere un archivo .env con DB_PASS). Pero para aprender, mejor hacé los pasos de arriba a mano.

ControlVerificar que funcionó

  • docker ps muestra 3 contenedores corriendo: mysql_global, pma_global y tarea_crud_web.
  • localhost:8001 abre la pantalla de login (fondo gris, barra azul marino).
  • Al registrarte e ingresar, ves la tabla con 5 productos de prueba y las métricas arriba.
  • localhost:8080 (phpMyAdmin) muestra la base tarea_crud_db con las tablas productos y usuarios.

Si algo fallaProblemas comunes

"The container name is already in use"

Ya existe un contenedor con ese nombre. Borralo y volvé a crearlo: docker rm -f mysql_global (o el nombre que sea), y repetí el paso.

"port is already allocated" / puerto ocupado

Algo ya usa el puerto 8001, 8080 o 3306. Cerrá ese programa, o cambiá el primer número del -p (por ejemplo -p 8002:80) y usá ese puerto.

docker build: "requires 1 argument"

Te faltó el . al final. Corré docker build -t tarea_crud_php:8.5 . (con el punto).

La página dice "Error de conexión a la base de datos"

Casi siempre es que la contraseña del Paso 4 (MySQL) no coincide con la de secrets.php (Paso 2). Deben ser idénticas. También puede ser que MySQL todavía esté arrancando: esperá 30 segundos y recargá.

Login o lista vacía / "table doesn't exist"

Faltó importar la base (Paso 8). Volvé a correr la Opción A o B de ese paso.

ReferenciaComandos útiles

# ver los contenedores corriendo
docker ps

# apagar los contenedores (NO borra nada)
docker stop tarea_crud_web pma_global mysql_global

# volver a encenderlos
docker start mysql_global pma_global tarea_crud_web

# ver los registros (por ejemplo, de la base)
docker logs -f mysql_global

# eliminar un contenedor (para recrearlo desde cero)
docker rm -f mysql_global
