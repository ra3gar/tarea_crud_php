El objetivoQué vas a instalar

Un sistema web de inventario de productos con login: podés crear, listar, editar y eliminar productos, con usuarios y recuperación de contraseña. Está hecho en PHP + MySQL y corre dentro de contenedores Docker.

¿Por qué Docker?

Docker empaqueta el servidor web, PHP y la base de datos en "cajas" aisladas. No tenés que instalar PHP ni MySQL en tu máquina: con un solo comando se arma todo igual en cualquier computadora. Eso es lo que hace que el proyecto sea reproducible para todo el grupo.

Antes de empezarRequisitos

Solo necesitás tres cosas. En el Paso 1 te muestro cómo instalar las dos primeras según tu sistema operativo.

  • Docker Desktop — el motor que corre los contenedores.
  • Git — para descargar el proyecto desde GitHub.
  • Un navegador (Chrome, Edge, Firefox…) — ya lo tenés.

Opcional: VSCode para ver y editar el código con comodidad.

Paso 1Instalá los requisitos según tu sistema

Elegí tu sistema operativo. Solo tenés que hacer la pestaña que te corresponde.

1

Activar WSL 2

Docker en Windows necesita WSL 2 (un Linux liviano por debajo). Abrí PowerShell como administrador y corré:

wsl --install

Reiniciá la computadora si te lo pide.

2

Instalar Docker Desktop

Descargá Docker Desktop for Windows desde docker.com, instalalo y abrilo. Esperá a que el ícono diga "Engine running".

3

Instalar Git

Descargá Git for Windows desde git-scm.com e instalalo con las opciones por defecto. Vas a usar la terminal Git Bash que trae.

Verificá

Abrí Git Bash y corré docker --version y git --version. Si ambos muestran un número de versión, estás listo.

1

Instalar Docker Desktop

Descargá Docker Desktop for Mac desde docker.com. Elegí la versión correcta: Apple Silicon (M1/M2/M3) o Intel. Arrastralo a Aplicaciones, abrilo y esperá a que diga "Engine running".

2

Instalar Git

La forma más simple: abrí la Terminal y corré git --version. Si no lo tenés, macOS te ofrece instalar las herramientas de desarrollo; aceptá. (O instalalo con Homebrew: brew install git.)

Verificá

En la Terminal corré docker --version y git --version. Si ambos muestran versión, estás listo.

1

Instalar Docker Engine + Compose

En Ubuntu/Debian (para otras distros, mirá la guía oficial):

sudo apt update
sudo apt install -y docker.io docker-compose-plugin
sudo systemctl enable --now docker

Para usar Docker sin sudo, agregate al grupo y volvé a iniciar sesión:

sudo usermod -aG docker $USER
2

Instalar Git

sudo apt install -y git
Verificá

Corré docker --version y git --version. Si ambos muestran versión, estás listo.

Paso 2Levantar el proyecto (igual en todos los sistemas)

Desde acá los comandos son los mismos en Windows (Git Bash), macOS y Linux. Docker Compose se encarga de todo.

1

Descargar el proyecto

En la terminal, ubicate donde quieras guardar el proyecto y cloná el repositorio:

git clone https://github.com/ra3gar/tarea_crud_php.git
cd tarea_crud_php
2

Configurar tu contraseña de base de datos

El proyecto trae un archivo de ejemplo .env.example. Copialo como .env y poné una contraseña local (la que quieras):

# copia la plantilla
cp .env.example .env

Abrí .env en un editor y dejá algo así:

DB_PASS=mi_clave_local_123
Por qué un .env

La contraseña vive solo en tu máquina (el .env no se sube a GitHub). El mismo valor lo usan la base de datos y la aplicación, así que con cambiarlo en un solo lugar alcanza.

3

Levantar todo con un comando

docker compose up -d --build

Esto hace, solo, todo lo siguiente:

  • Construye la imagen de PHP con los drivers de MySQL.
  • Levanta MySQL, phpMyAdmin y la app.
  • Crea la base y la tabla e inserta datos de prueba (la primera vez).
Paciencia la primera vez

La primera vez descarga imágenes y prepara la base: puede tardar 1–3 minutos. Esperá ~30 segundos extra después de que termine para que MySQL arranque del todo.

4

Abrir la aplicación

En el navegador, entrá a:

http://localhost:8001

Como es la primera vez, hacé clic en "Crear cuenta", registrate (usuario, contraseña y una pregunta de seguridad) y después iniciá sesión. ¡Ya estás adentro del inventario!

Bonus: ver la base de datos

phpMyAdmin queda en http://localhost:8080. Usuario root y la contraseña que pusiste en el .env.

ControlVerificar que funcionó

  • docker compose ps muestra 3 contenedores "running".
  • localhost:8001 abre la pantalla de login (fondo gris, barra azul marino).
  • Al registrarte e ingresar, ves la tabla con 5 productos de prueba y las métricas arriba.
  • localhost:8080 (phpMyAdmin) muestra la base tarea_crud_db con las tablas productos y usuarios.

Si algo fallaProblemas comunes

"port is already allocated" / puerto ocupado

Algo ya usa el puerto 8001, 8080 o 3306. Cerrá ese programa, o cambiá el puerto en docker-compose.yml (por ejemplo "8002:80") y volvé a correr docker compose up -d.

"docker compose: command not found"

Tenés una versión vieja de Docker. Probá con guion: docker-compose up -d --build, o actualizá Docker Desktop.

La página dice "Error de conexión a la base de datos"

MySQL todavía no terminó de arrancar: esperá 30 segundos y recargá. Si sigue, revisá los logs con docker compose logs mysql_global y confirmá que tu .env tiene DB_PASS.

Cambié schema.sql y no se reflejó

La base solo se importa la primera vez. Para recrearla desde cero: docker compose down -v y luego docker compose up -d --build. Ojo: -v borra los datos.

.env.examplePlantilla de la contraseña; cada quien crea su .env.

login · registro · recuperar · logout.phpAutenticación y recuperación por pregunta.
auth.phpProtege las páginas privadas (exige sesión).
database/schema.sqlCrea la base, las tablas y los datos de prueba.
includes/Encabezado y pie comunes a todas las páginas.
assets/Estilos propios, Bootstrap y fuentes (locales).
DOCUMENTACION_MD/Contexto y decisiones del proyecto.

ReferenciaComandos útiles

# levantar todo (en segundo plano)
docker compose up -d

# ver el estado de los contenedores
docker compose ps

# ver los logs (por ejemplo, de la base)
docker compose logs -f mysql_global

# apagar todo (conserva los datos)
docker compose down

# apagar y BORRAR la base para empezar de cero
docker compose down -v
